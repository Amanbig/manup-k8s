# ManUp Kubernetes Suite v0.1.0

Initial public release of the **ManUp Kubernetes Suite** (`manup-k8s`), providing native Kubernetes integration and zero-storage secret injection for ManUp.

---

### 🚀 Key Features in v0.1.0

- **Official Helm Chart (`charts/manup`)**:
  - Full support for deploying ManUp with embedded `PGLITE` database persistence via PVC.
  - Optional external PostgreSQL database support (`DATABASE_URL`).
  - Kubernetes Ingress and ClusterIP Service configurations.
  - Pre-configured liveness and readiness probes against database-aware `/health` endpoint.
- **Mutating Admission Webhook Controller (`injector`)**:
  - Intercepts Pod creation requests matching `manup.io/inject: "true"`.
  - Automatically generates RFC 6902 JSON patches injecting `tmpfs` RAM volumes (`medium: Memory`).
  - Injects lightweight init container (`manup-secrets-init`) to securely fetch and decrypt secrets before the application process boots.
  - Zero plain secrets written to physical disks or Kubernetes etcd.
- **Multi-Arch Docker Images**:
  - Controller image built for both `linux/amd64` and `linux/arm64`.
  - Published to Docker Hub (`procoder588/manup-injector:0.1.0`) and GHCR.
