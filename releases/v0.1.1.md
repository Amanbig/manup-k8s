# ManUp Kubernetes Suite v0.1.1

Release **v0.1.1** focuses on release automation, zero-configuration TLS certificate generation, and unified Helm packaging.

---

### 🛡️ Improvements in v0.1.1

- **Automated Version Synchronization**:
  - Pushing a Git tag (`v*`) now automatically synchronizes and packages the Helm Chart with the exact matching version (`manup-0.1.1.tgz`).
  - Webhook injector deployment automatically defaults its image tag to match the Helm chart version.
- **Zero-Config Webhook TLS**:
  - The Helm chart now utilizes Helm's built-in cryptographic engine (`genCA` and `genSignedCert`) to provision the Mutating Webhook CA and server certificates on the fly without requiring `cert-manager` or external OpenSSL scripts.
- **Direct Release Distribution**:
  - Pre-packaged `.tgz` chart archives are automatically uploaded and attached as downloadable release assets to GitHub Releases.
- **OCI Registry Publishing**:
  - Enabled automated Helm chart publishing as OCI artifacts to GitHub Container Registry (`ghcr.io/Amanbig/charts/manup`).
- **Comprehensive Documentation Suite**:
  - Added dedicated documentation for [Annotations Reference](docs/annotations.md), [Architecture Lifecycle](docs/architecture.md), and [Application Integration](docs/application-guides.md).
